## Callback и запуск Work

Прежняя реализация raw TCP возвращала callback_network_error: callback OpenAI
размещён за Cloudflare, а исходящие TCP sockets Workers к Cloudflare IP запрещены
[платформой](https://developers.cloudflare.com/workers/runtime-apis/tcp-sockets/#considerations).
До этого также исправлено различение CNAME и фактических A-адресов в resolve4.

Теперь используется public-only global fetch Workers с явно включённым
global_fetch_strictly_public. Точный callback hostname проверен оператором;
HTTPS:443, запрет userinfo/IP literals/fragment/redirects, DNS preflight,
проверка TLS исходного hostname, 8 секунд и 64 KiB сохранены. Фактическую
публичность адреса при соединении обеспечивает runtime, включая изменение DNS
после preflight. Это не ручная привязка отдельного DNS-ответа к fetch. Контракт,
первичные источники и ограничения описаны в [ARCHITECTURE](../ARCHITECTURE.md).

После deploy настоящий ChatGPT events/subscribe успешно прошёл signed challenge
для telegram.comment.created и telegram.comment.updated. Две подписки появились
в статусе; задача «Проверка комментариев Telegram» сохранена в существующем Work
«Проверка статуса подключения». Доставка настоящих событий получила 2xx и
запустила Work без ручного запроса анализа. Полные callback URL, signing keys,
OAuth query и тексты комментариев не включались в техническую трассировку.

## CPU на Workers Free

Ранняя версия дала 12 мс CPU внешнего Worker на одном настоящем edited_message,
хотя HTTP вернулся 200. Gateway упрощён: API обходит Hono router, кэшируется
только неизменяемый ID owner/bot DO. Все прежние проверки секрета, размера,
Content-Type и Origin остаются до DO и повторяются внутри него. Stub создаётся
заново после каждого вызова; комментарии и авторизация не кэшируются.

После текущего deploy безопасный tail дал следующие измерения:

| Запрос | HTTP | Внешний Worker CPU | DO CPU | Worker wall time |
|---|---:|---:|---:|---:|
| Два первых запроса разных изолятов: подписанные пробы вне allowlist | 200 | по 2 мс | — | — |
| Следующие 10 проб | 200 | 0–1 мс | — | — |
| Настоящий новый комментарий с сохранением job и event | 200 | 2 мс | 4 мс | 145 мс |
| Настоящее редактирование перед auto тестом | 200 | 3 мс | 3 мс | 138 мс |
| Последнее редактирование, завершившееся auto-удалением | 200 | 3 мс | 2 мс | 164 мс |

Метку первого вызова выдаёт конкретный isolate только для аутентифицированной
пробы; это свидетельство первых запросов двух изолятов, не управление всеми
возможными cold starts. Пробы не создают job и не заменяют настоящий сценарий.
0 мс — округление метрики, а не отсутствие вычислений.

Alarm доставки последнего события: CPU=4 мс, wall=7998 мс, успешная доставка;
для нового комментария CPU=6 мс, wall=4484 мс. Сетевое ожидание входит в active
duration DO, но не является CPU и не держит внешний Worker в ожидании модели.
DO CPU имеет собственный лимит, его нельзя смешивать с 10 мс внешнего Worker.

Cloudflare GraphQL workersInvocationsAdaptive, снимок 10:42:35 UTC за окно с
10:34 UTC: 46 успешных запросов, 0 errors, CPU P50=1067 µs и P99=3313 µs
(1,067 и 3,313 мс). Это агрегат внешнего Worker. Startup Time сборки и HTTP
round trip не используются как доказательство CPU.

Эта выборка укладывается в Free; гарантии любого будущего cold start или
неограниченной нагрузки она не даёт. SQL rows и суммарный DO duration под нагрузкой
не измерены. [FREE_TIER_BUDGET](../FREE_TIER_BUDGET.md) остаётся плановой моделью.
Перед увеличением cap нужны соответствующие production измерения.

## Локальные проверки и эксплуатационные пределы

Node 24.18.0, pnpm 11.15.1. `pnpm check`: typegen, Biome, module boundaries,
TypeScript, **41 тест**, две dry-run сборки. Новые регрессии проверяют ранний

public-only конфигурацию, callback DNS/private answers, запрет redirects,

Моки в тестах сами по себе не доказывают живую интеграцию — её результаты выше.

Подписки имеют конечный TTL (по умолчанию 24 часа). Долгосрочное обновление
реальным сервисом ChatGPT, rotation/unsubscribe и поведение при исчерпании
квоты в этой среде ещё не проверены; протокол и обработчики покрыты локально.
ChatGPT имеет отдельный лимит: последний UI-снимок показал **2%** остатка,
следующий недельный сброс — 22 октября в 11:15. При исчерпании лимита модель
может перестать запускаться; платный fallback отсутствует. Это существенный
предел текущего автоматического режима, даже при исправном Cloudflare.

Локальные CPU-артефакты и скриншоты находятся в игнорируемой `.local`;
тексты, токены и callback URL в технические логи и git не включены.
