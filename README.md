# Telegram Comment Moderator

Событийная модерация комментариев Telegram-канала с анализом через ChatGPT и MCP.

## Возможности

- Приём webhook и сохранение событий.
- Запуск анализа через MCP Events и получение решения инструментом.
- Проверка допустимости действий, очередь обработки и сохраняемые фоновые задачи.

## Инженерные акценты

- Интеграция AI-решений с контролируемым серверным исполнением.
- Обработка повторных событий и восстановление после сбоев.
- Разделение решения модели, правил доступа и внешних действий Telegram.

## Стек

TypeScript, Hono, Vitest.

## Навигация по коду

- [src/modules/](src/modules/) — предметные модули.
- [src/](src/) — исходный код.
- [test/](test/) — автоматизированные проверки.
- [docs/](docs/) — архитектура и документация.

## Разработка

Инструменты: Node.js 24, pnpm@11.15.1.

```sh
pnpm install
pnpm dev
pnpm check
pnpm test
```

Параметры окружения перечислены в [.dev.vars.example](.dev.vars.example). Локальные значения задаются вне Git.
